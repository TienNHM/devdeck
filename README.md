# devdeck

A tiny, single-binary developer dashboard. Go backend, no-build web UI, low RAM.

## Planned features

- Ports and processes: see what listens where, kill it
- Git graph: commit graph like the VS Code extensions
- Redis browser: scan keys, inspect values and TTLs
- SSH and local terminal (xterm.js over WebSocket)
- Claude Code integration: MCP server (`devdeck mcp`), embedded `claude` terminal, hook-based session status

## Status

Early work in progress. Nothing here is stable yet.
